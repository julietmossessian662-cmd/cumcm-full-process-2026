# cumcm-full-process-2026 · CUMCM 国赛「全流程作战」技能包

## 包里有什么

- **方法论文档（references/）**
  - `全流程作战手册-2026.md` —— 核心手册：备赛 → 选题之夜 → 分工协作 → AI 协同流水线 → 建模验证 → 论文工程 → 合规红线 → 提交日 Playbook
  - `因子频率分析.md` —— **参考因子体系：提取自往届历年论文**（28 篇全样本频次统计 + 趋势/近因权重法）
  - `验证优先.md` —— 数值验证方法论（含两个真实反直觉案例）
  - `交互服务模拟.md` —— 模拟器类题的攻防演练思路
  - `公开出库红线-2026.md` —— 公开前的敏感信息扫描流程
- **LaTeX 论文工程骨架（templates/论文骨架/）** —— main / preamble / 摘要页 / 章节占位 / build.bat / compile_check.sh，复制即用
- **通用脚本（scripts/）** —— 配图、渲染目检、全文核查、支撑材料打包、知网检索、因子频率扫描

## 快速开始

- **Agent 使用者**：把 `cumcm-full-process-2026/` 整目录复制进你的 skills 目录即可；入口 `SKILL.md`，按「何时用」自动触发。
