# 公开出库 · 红线扫描与三桶分类

用于把本技能 / 手册 / 过程材料改写成公开版（GitHub）前的检查。
原则：**"不会暴露个人信息"必须由扫描证明，不能凭感觉。**

## 扫描命令（只读，先扫后改）

```bash
grep -rn -E '<队号前缀>|<学校名>|<赛区>|<队员姓名>|Users.<用户名>' <候选目录> --include='*.md' --include='*.py' --include='*.sh' --include='*.ps1'
```

（Windows git-bash。候选 = 技能目录 / 手册 / 脚本层。脚本层先 `--exclude-dir` 掉 venv、tmp 等大目录。）
补充模式：邮箱、QQ/微信、Windows 用户名、`C:/Users/...` 类硬路径、旧目录名。

## 常见命中与处理（实战经验）

| 命中类型 | 处理 |
|---|---|
| 队伍画像含学校 / 赛区 / 年级 | 泛化为"典型队伍画像"，保留通用特征 |
| 脚本里写死本机路径 | 改占位符 / 配置文件 / 命令行参数 |
| 文档里个人工作流（笔记库位置等） | 删除，或改写为通用建议 |
| 扫描文档自身含示例串 | 示例一律用 `<占位符>`，不出真实值 |

## 三桶分类

- 🟢 **直接可发**：流程/方法/避坑/合规条目表；把"个人偏好"改写为"通用建议"。
- 🟡 **通用化后发**：脚本（本机路径 → 参数/配置、队号 → 命令行参数）、LaTeX 论文工程骨架（模板化、抽掉赛题数据）。
- ⛔ **永不出库**：提交包原件、审计日志/统计队列（官方资料）、含正式队号或来源账号的任何文件、赛题原文与官方附件（版权归组委会）、聊天记录/浏览器配置/飞书数据。

## 发布前纪律

全量扫描 → 逐条处理 → 相关方确认 → 推仓库。
（本文件自身也受扫描约束——示例一律用占位符。）
