# 全样本因子频次分析（把"论文逆向"从主观判断升级为证据）

> 来源：2026-09-11，28 篇获奖论文（25×5 + 24×12 + 23×11）全样本频次分析 → 因子体系 v0→v1。
> 适用：任何"逆向评奖标准 / 从获奖样本提炼要素"的任务；新一年份样本到手时的标准动作。
> 脚本：`scripts/因子频率扫描.py`（本技能内，可直接跑）；该脚本由一次真实参赛项目提纯而来。

---

## 一、先查这个陷阱：**文本提取 ≠ 分析完成**

实战：23 年 11 篇 + 24 年 12 篇的全文**早已提取到 `ocr/`**，但两份分析笔记的"差异核对"节 **一直是空的**——只做了审题 + 预判就搁置了，于是因子体系卡在"只有 1 年证据"的主观版。

**标准动作**：宣布某年份"分析完成"之前，**先读该年份笔记的"差异核对/结论"节**；空的就是没做。文本在盘上 = 分析成本极低（几分钟），别让它烂尾。

---

## 二、方法（两步，成本低到可以每次都跑）

### 步 1：关键词频次全样本扫描
对每篇统计：因子指示词命中数 + 结构信号（摘要字数、高精度数字个数、参考文献条数）+ 按年/按题型分组汇总。

- **宽窄口径都要跑**：窄口径（`创新点`）命中 **0/28**；宽口径（`创新|特色|亮点|改进之处`）命中 **26/28**。
  ⚠️ **命中率为 0 时先怀疑口径，不要下"该因子无价值"的结论**——这是最容易犯的错。
- "验证"类同理：严格词（`交叉验证`）32%，宽口径（`验证|校验|印证|比对|结果对比`）93%。**国奖的写法很多样，一个词代表不了做法。**
- 指标设计原则：**测"行为"而非"词"**——但凡是词，就要给同义词族。

### 步 2：同型论文精读用"摘要 + 骨架" digest（不要读全文）
单篇 2–9 万字符，全读会淹掉上下文。只提取：
```
摘要全文（"摘要" → "关键词"）＋ 关键词行
章节标题行（正则：第X章 / 数字编号 / 括号编号，且含"模型|分析|求解|验证|灵敏度…"）
表/图引用编号数 ＋ 参考文献条数
方法词频（贪心|模拟退火|粒子群|遗传|蚁群|贝叶斯|假设检验|动态规划…）
```
→ 6 篇同型论文 digest ≈ 十几 KB，**可一次性精读完**，这才是能读出"打法"的量级。
方法词频还能一眼看出"谁堆了几个算法"（实战：24 年 B 组两篇堆了 4–5 种启发式）。

## 三、结果：四层分级框架（可复用到任何逆向评奖任务）

| 层 | 阈值 | 处置 |
|---|---|---|
| 🟥 及格线 | ≥85% 命中 | 不做就掉档，**必做** |
| 🟨 加分项 | 60–84% | 该做 |
| 🟩 区分度项 | 30–59% | **决定名次**（低频才是差异所在） |
| 🟦 低频高价值 | <30% | 看**趋势**判断，不能只看总命中率 |

---

## 四、⭐ 最重要的发现：看趋势，不看总命中率

用"最近一年 vs 更早年份"的**同比差**找水位线漂移。实测（25 年 vs 24/23 年）：

| 指标 | 24/23 年 | 25 年 | Δ |
|---|---|---|---|
| 不确定度/置信区间 | 13% | **80%** | +67pp |
| 伪代码 | 30% | **100%** | +70pp |
| AI 申报 | 0% | **80%** | +80pp |
| 交叉验证类 | 30% | 80% | +50pp |
| 鲁棒性 | 35% | 80% | +45pp |
| 灵敏度 | 57% | 100% | +43pp |
| 统计检验 | 39% | 80% | +41pp |

**结论：最近一年是分水岭**——新一届国奖的隐藏门槛 ≈ **上一届**的水位，用更早年份的写法会输。
**推论**：总命中率低但**近年突然变高**的指标（不确定度 25% 总 / 80% 近年；AI 申报 14% 总 / 80% 近年）必须按"近年"处理，否则会漏掉正在形成的新门槛。

配套做法：**近因权重**（用户指定 25/24/23 = 45/35/20）；把趋势差 >25pp 的指标单独列一张"警报表"。

## 五、量化红线（写作阶段的硬指标，28 篇实测）

| 指标 | 实测 | 目标 |

## 六、三处认知修正（v0 → v1 的实证）

1. **"创新点显式声明"是措辞问题**：`创新点` 一词 0/28；`创新|特色|亮点|改进之处|优点` 26/28 → 国奖**不写"创新点"**，写在模型评价里用"特色/优点/改进"。
2. **"模型推广"第不再是必备章**：仅 11/28 = 39% → **降级为可选加分项**（不要塞进骨架当必填）。
3. **"验证工程"不是低频，是口径问题**（见上方宽窄口径）。

## 七、同型样板法：找一篇同型国奖论文当骨架

**比读十篇不同类型论文更有用**：挑形态最接近的一篇精读，把它的"打法链"直接映射到本题。

实战样板（23 年 B 题 B226，几何覆盖+优化型）：

| B226 做法 | 原文证据 | 对应动作 |
|---|---|---|
| **先数学证明再求解** | "利用数学证明得到…是最佳方案" | 本题的覆盖性/最优性证明 |
| 单目标优化 | "以总长度最短为目标，以完全覆盖…为约束" | min 时间 s.t. 约束 |
| 贪心求精确解 | "贪心循环遍历得 34 条 / 125936m" | 路径/布点贪心 |
| **双算法交叉验证** | "用模拟退火仿真检验，两种方法误差很小，验证模型可靠性" | 独立方法对拍 |
| 灵敏度 | "对开角、坡度进行灵敏度分析" | 2–3 个物理参数 |
| **结果分析 + 原因分析分两段** | "最后进行结果分析以及原因分析" | 报数据（现象）+ 讲机理 |
| 摘要逐问 + 精确数字 | 34 条 / 125936m / 3.48% | 量化结果进摘要 |

## 八、对拍评审框架（评队友/平行版本报告时）

**四轴打分**：① 原题符合度（逐问对照，有无答非所问）② 数学严谨性 ③ 答题完整性（每问是否真的给出了所问的东西）④ 获奖因子对齐（用上面的分层表逐条过）。
再加两栏：**"我方有对方缺"**（缺口，可对拍互补）与 **"对方有我方缺"**（要采纳）。

**纪律：只给方向不给答案**——平行版本的价值在独立性，直接给答案等于合并成一版。
**交叉验证的收益常大于各自结论**：实战中对方的定性原则（"交会角接近 90° 条件数最低"）是对 的，我方"ψ=90°"的表述错在**混用了两个名字相近的量**（ψ = 第二点相对示向度的偏角；φ = 两条视线在源处的交会角——ψ=90° 只给出 φ=45°）。→ 详见 `验证优先.md` 案例 2 的补充。

## 九、实现坑

| 坑 | 正解 |
|---|---|
| Python <3.12：f-string 表达式里不能有反斜杠（正则含 `\[`） | 先 `re.compile` 到变量，再用 `%` 或 `.format` 拼接 |
| 长脚本 `write_file` 可能被截断（落盘 400 字节 + 语法错误） | 看返回的 `bytes_written` 与 lint；失败就**整份重写**，不要逐行补 |
| 用 grep 数 emoji/Unicode | 用 Python 文件统计；**验证逻辑落盘成 `.py` 再跑**，不要 `python -c` 内联（bash 会吞反引号与中文） |
| 只跑一种口径就下结论 | 宽窄口径都跑，命中率异常先查口径 |

## 十、诚实边界（写进论文/汇报时必须声明）

关键词统计只反映"**是否提及**"，不反映"**做得多深**"；OCR 可能有漏字；样本**全是获奖论文、无对照组** → **不能推因果**，只作"同类论文的共性与趋势"参考。任何"做了 X 就能获奖"的表述都是过度解读。
