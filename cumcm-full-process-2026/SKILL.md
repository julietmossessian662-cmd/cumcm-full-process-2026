## 二、适用队伍画像（经验来源：数学基础一般 + 代码主要靠 AI 的队伍）

## 三、选题判断方法论（用户指定偏好）
- 多维度加权打分；**每项必须大白话解释"是什么/为什么重要/代价"并给推荐**（只列选项名读者看不懂）；权重比例按队伍实际微调。
- 2026 采用裁判/获奖视角维度与权重（**v2，已用 23/24/25 三年 28 篇获奖论文校准**）：分题竞争格局 25 / 客观硬成绩·验证工程可行性 25 / 四问完整完成 20 / **论文可写性 15**（摘要与章节模板化程度高，AI 可复制，数学弱也能凑齐结构）/ **创新点提炼难度 10**（证据：创新可被验证工程、落地应用、方法组合替代，非硬门槛）/ 合规风险 5。
- 评分结论（v2）：**B 7.65 > C 5.80 > A 4.45**，推荐 B，且对权重扰动稳健。三年证据背书：B 类算法策略题的获胜要素（客观硬指标+无限演练验证+策略创新可演示）恰落在三年最强规律上。
- 国赛机制要点：A/B/C 分题评阅、按名额送全国；强队主力堆 A/C 组；匿名盲评（学校牌子不起作用）；各赛区竞争强度与名额倾斜以当年细则为准。

## 三·五、官方尺子：赛区评阅规范（依据 2023/2025 修订稿整理）
- **查重红线**：知网 或 竞赛自建库 相似度 **≥25% → 原则上不能报送全国**；自建库=当年全部参赛论文（和别人雷同也炸）。→ AI 生成文本必须个性化改写，摘要最易撞车。
- 匿名随机编号 + 回避制度（同组同校评委 ≤1 人）+ 每篇 **≥3 评委独立评阅** + 分歧复议。
- **面试（答辩）**：范围由赛区定 → 时间表预留半天，全队要能讲清模型。
- **同校每题报送 ≤4 篇（一等 ≤2 篇）**；申报一等 ≤ 报送数 40%；申报二等奖原则上不能获全国一等。
- 创新点破格报送：每题每赛区最多 1 篇。
- 报送基数：报名 ≤200 队部分 ×12% / 200~500 ×10% / 500~800 ×8% / >800 ×5%；本科组 A=min(2000, 总报名×8%)、B=6 保底。2025 修订新增"名额倾斜办法"（试行）。
- 评阅要点→细则随题而定、不公开 → 逆向分析优秀论文仍是最佳替代手段。

## 四、优秀论文逆向分析工作流（推荐方法论）
顺序 25→24→23 年。每轮四步：①审题（先读赛题与附件）②写预判（读论文前先写"国奖论文长什么样"清单）③OCR 论文并对照找差异 ④修正认知/调权重。
- 操作要点：**一步步来、聚焦文档、及时汇报进度**；选题结论放在资料分析之后（不要提前跳步）。
- **协作纪律（AI 协作建议）**：读取/分析可放手进行；**写操作（建/改/删文件、执行命令、启动程序、改配置）先确认再执行**，逐步执行并汇报；知识沉淀（写笔记库）可自动化。
- 近因权重（建议）：**25/24/23 = 45/35/20**，23 年只做"差异补丁"（定向检索、不逐篇通读）。因子强度用**频次统计**（28 篇中 X 篇做了 Y），不靠主观星。
- 文本获取优先序：**先测文字层**（pymupdf 前 5 页 get_text，≥~500 字符/页 即直接提取——23 年 11 篇全有文字层、零 OCR 成本）→ 无文字层才走 OCR 流水线（`scanned-pdf-ocr` 技能）。
- **文件组织建议**：知识沉淀进笔记库（如 Obsidian）；原始素材（OCR 全文、赛题、脚本）独立存放；论文工程独立目录——三处分离，互不污染。
- OCR 流水线（扫描件 PDF→txt）见 `scanned-pdf-ocr` 技能。

## 四·五、解题工作流（用户指定顺序，2026-09-11 纠正）

**顺序不可跳步**：审题/读题 → **问题拆解** → **解题设计** → 执行（代码/演练/测试）→ 论文转化。

- 常见坑：不要从"审题/四问解析"直接跳到"数学模型选型"（后者属解题设计）。**解析 = 读懂题意；拆解 = 把题变成工程规格**——缺这层，解题设计就没有正式输入。
- **每问拆解七要素**：已知（输入）/ 未知待求 / 决策变量 / 约束 / 目标函数 / 交付物（论文里对应哪张表、哪个小节）/ **评委看点**（这问他们看什么：数学严密性？判据合理性？客观硬指标？）。
- **11 条优势因子逐阶段嵌入**（"不脱离多因子"的落地方式）：拆解阶段标出每问的"可验证点"；设计阶段设计验证方案；执行阶段跑验证留数据；论文阶段写"结果分析与验证"小节。
- **评委高分要素 → 交付物检查清单**：把评阅规范与他人技巧落成"每项检查 + 谁检查 + 何时检查"（摘要一页含量化结果 → 三号/定稿前；每问带验证小节 → 一号/每章完成；查重<25% + MD5 校验 → 三号/提交前；支撑材料日志不改名 → 一号/测试后）。**只列清单不绑人绑时间 = 不会被执行。**
- 交付样例（以 2026 B 题为例）：问题拆解表 / 整体解题设计 / 数学模型选型 / Q1 论文级方案。

## 四·六、⭐ 解析结论必须过数值验证（2026-09-11 教训，通用）

任何解析推导或几何直觉，**写进论文前先写数值验证脚本**。两个"听起来很对但错"的实证案例：

1. **"定位区域是平行四边形"** ❌ —— 把"射线带"类比成"平行带"。实际两条边界射线**共起点**（交于检测点）是**楔形**；1500 例随机几何中 **0 例**满足平行四边形判定。→ **类比对是建模中最危险的一步**（"带"这类词会诱导错误类比）。
2. **"第二检测点最优 ψ=90° 垂直侧翼"** ❌ —— "交会角接近 90° 定位最准"听着对，但对着"面积/直径"判据是反的：d=L₁ 时 A = 8ε²L₁²·tan(ψ/2) **随 ψ 单调递增**。

做法（已验证有效）：

- 每个解析结论配三件套：**独立方法交叉验证**（暴力 vs 二解、公式 vs 几何计算、解析最优 vs 网格搜索）+ **蒙特卡洛批量**（随机几何/参数千例统计成立率）+ **灵敏度表**（参数扫描出真实数字，不靠手工估算）。
- 批量判定用**相对容差**（极端/长条几何下绝对误差可达 1e-4，用 1e-6 绝对容差会大批误报"失败"）；报告要给"最大越界幅度"，不能只给失败计数。
- 结论有三种：成立 / **有条件成立** / 不成立。"有条件成立"要写成 **"充要条件 + 反例 + 定量统计"**（如覆盖性 99.47% 成立、0.53% 超出 ≤0.06%），比单字"能/不能"严谨得多——正是评阅规范强调的严谨性，25A196 同款"引理+反例"打法。
- **推翻旧结论必须留痕**：旧笔记顶部加 🔴 警示 + 写"修正记录"表，并 **grep 全库同步所有连带引用**（看板、模型选型、下游问题解析都可能引用了错结论）。
- 细节与可复用脚本模式见 `references/验证优先.md`。

## 五、国奖论文 DNA（三年 28 篇实证：25×5 + 24×12 + 23×11，全部走完"审题→预判→对照→调权重"）
通用模板：摘要固定句式"针对问题X：方法→结果数字（3~6 位）"；逐问问题分析；假设清单+符号约定；递进式建模（由简到繁）；**每问后带验证小节**；模型评价章（优点/缺点/展望）；参考文献带具体数字；附录支撑材料目录。
分题型差异：
- A 优化/运动题：数学证明 + 算法交叉验证（两算法互验报相对误差）+ 灵敏度分析 + 降维技巧。
- B 物理信号处理题：**结果可信度工程**（多方法交叉印证 + 多维度可靠性检验，B157 做到七连检）+ 异常数据诚实处理。
- C 统计题：统计检验仪式感（LMM/R²/ICC/AIC/FDR）或 ML 深度（集成/独立验证集）二选一做到极致 + 创新点显式声明 + 落地应用（交互网页）加分。
四个修正认知（反直觉）：①国奖=经典方法+极致验证，而非发明新算法（可复制性强，利好 AI 辅助队伍）；②AI 申报是国奖惯例；③深度>广度（28 页统计流与 65 页 ML 流同题都拿奖）；④落地应用是低成本高回报加分项。
跨年确认的规律（24/23 年复核后新增）：⑤**答案分歧但都获奖**——24A 最小螺距 0.45/0.40 m、最大速度 1.406/1.33/1.246 m/s；24C 七年利润 1792万~4530万；23A 确定性 Q1 光学效率 0.6051 vs 0.4902、塔位 (0,-79) vs (0,-237)。→ 评委看模型自洽+论证+验证，**不看唯一数值答案**（对数学弱队伍是结构性利好）；⑥工具不决定成败（GA/DE/PSO/LINGO/贪心/MC/蚁群/SA/飞蛾火焰/LSTM/Prophet/MCMC/VAR/NSGA-II 均有获奖）；⑦分题型 DNA 增补：纯决策推导题（24B）=概率统计工具链完整（假设检验→功效函数→期望决策→DP→贝叶斯→灵敏度）；规划题（24C）=约束工程（6~12 类显式）+不确定性分层（CVaR/随机规划/风险决策/灾害因子）+方法对比意识；数据题（23C/25C）统计流与 ML 流跨年都成立；⑧AI 申报时间线：24 年 12 篇零提及 → 25 年国奖引用 DeepSeek-V3.1+附录《AI使用说明》 → 26 年规定正式化（2026 申报=常规操作）。
