# CUMCM 论文工程骨架（论文骨架）

从 2026 实战工程提纯的 LaTeX 骨架：**直接复制整个目录**开始一篇新论文。

## 用法

1. 复制整个目录到你的论文工程位置（如 `<你的目录>/paper/`）；
2. `preamble.tex` 一般不用改（已按格式规范：页边距 2.5cm、页脚居中页码、中文数字章节号、XITS 数学字体、GB/T 7714 参考文献）；
3. 依次填写 `sections/01–09`；图放 `figures/`；**摘要页 `frontmatter/abstract.tex` 最后写**（一页红线）；
4. 附录 `appendix/appendix.tex`：支撑材料目录（条目让评委一眼看到主程序）+ 运行说明 + 核心程序清单（节选）；
5. 编译：
   - Windows：双击 `build.bat`；或命令行 `latexmk -xelatex main.tex`
   - 验收：`bash compile_check.sh` —— 三项计数必须为 0（错误 / Overfull / Missing character）

## 文件说明

| 文件 | 说明 |
|---|---|
| main.tex | 主文件：摘要页 → 九章 → AI 声明 → 参考文献 → 附录 |
| preamble.tex | 导言区（全部宏包与格式设置） |
| .latexmkrc | latexmk 默认 xelatex |
| build.bat | 双击编译（CRLF 行尾） |
| compile_check.sh | 编译 + 三计数验收（终版纪律用） |
| frontmatter/abstract.tex | 摘要页占位模板（一页红线 + 句式提示） |
| sections/01–09 | 章节占位（问题重述 → 模型评价与推广） |
| appendix/appendix.tex | 附录占位（A 支撑材料目录 / B 运行说明 / C 核心程序清单） |
| refs.bib | 参考文献库占位 |

## 坑（完整清单见技能 `chinese-latex-papers`）

- latexmk 误判 up-to-date → **直接 `xelatex` 连编两遍**（compile_check.sh 已按此实现）；
- listings 源码保持纯 ASCII（emoji/数学符号必然缺字）；
- 样式名用 `gbt7714-2015-numeric`（`gbt7714-2015` 不存在）。
